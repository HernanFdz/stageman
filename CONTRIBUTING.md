# Contributing

This file exists because GitHub links it from the pull-request form and people
look for it by name. It is a pointer, not a copy — everything it would say is
already somewhere that is kept up to date.

- **[AGENTS.md](AGENTS.md)** — what to install, what to run before you start,
  how we work, and where each kind of sentence belongs. Read it first. It is
  written for whoever picks this up next, whether that is a person or an agent.
- **[docs/conventions.md](docs/conventions.md)** — the rules particular to this
  project: its vocabulary, its house rules, and the quality bar the gate does
  not enforce mechanically.
- **[docs/](docs/)** — why this exists, what shape it has, and what has already
  been decided against what.

The short version: run `just check` before you claim anything is done, align
the docs in the same commit as the change, and say what you rejected and why.
